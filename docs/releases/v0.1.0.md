## SoundCast v0.1.0 首个正式版本发布

**SoundCast** 是一个极简、超轻量的 Windows 桌面工具，能够根据应用窗口当前所在的显示器，自动将该应用的音频输出切换到对应的播放设备。

### 下载说明
- **`SoundCast_v0.1.0.msi`**（推荐）：Windows 安装包（`perMachine` 模式），支持默认安装到 `C:\Program Files\SoundCast\` 或任意自定义盘符/目录（未包含 `\SoundCast\` 时自动拼接子目录，防止文件散落根目录），提供桌面与开始菜单快捷方式、安装完成一键启动及后续升级记忆原安装路径。
- **`SoundCast_v0.1.0.zip`**：绿色便携压缩包，解压后直接运行 `SoundCast.exe` 即可（同目录新建空 `config.toml` 即启用便携配置模式）。

### 主要特性
- **超低后台资源占用**：采用“Win32 后台守护进程 + 按需启动 Slint Fluent UI 子进程”架构，关闭设置窗口后即刻释放全部界面内存。
- **单应用独立音频路由**：基于 Windows `AudioPolicyConfig` 接口实现进程级音频输出重定向，不影响系统全局默认播放设备。
- **多进程应用兼容**：自动匹配同一可执行路径的音频子进程，支持 Chrome、Edge、Discord、Electron 等应用跨屏精确切换。
- **Windows 11 Fluent 设置界面**：支持深浅色自适应主题、启动自动居中、显示器与音频设备映射、防抖延迟设置、项目主页展示与点击访问，以及设备热插拔刷新。
- **灵活的忽略与关闭控制**：支持从运行中进程带图标选择添加忽略列表（默认为空），支持开机自启动（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`），点击窗口关闭按钮（`×`）可选择隐藏到托盘或彻底退出并记住偏好。

### 系统要求与注意事项
- **系统要求**：Windows 10 (1803+) / Windows 11（64 位）。
- **配置文件路径**：默认保存在 `%APPDATA%\SoundCast\config.toml`。
- **已知限制**：
  - 部分使用独立音频引擎的第三方播放器不会即时响应进程默认音频端点的动态切换，可能需要暂停/继续或切歌重建音频流后生效。
  - Chromium 系浏览器同一实例下的多个窗口共享同一个音频子进程，跨屏时会随窗口所在显示器整体切换，暂不支持按单个标签页独立路由。
