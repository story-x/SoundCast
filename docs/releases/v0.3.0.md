## SoundCast v0.3.0 视觉与交互体验升级发布

本次版本在 `v0.2.0` 的基础上，重点完成 **全新品牌图标与界面 Logo 焕新**、**手动深浅色主题切换** 以及 **设置界面细节与状态反馈打磨**。

### 新增与改进
- **全新应用图标与界面徽标**：
  - 统一更新桌面应用图标（`icon.ico` 多尺寸高清重制）、窗口图标（`icon.png`）、系统托盘图标（`tray_32.rgba`）以及设置页头部 Logo（`logo.png`）。
- **支持「自动 / 浅色 / 深色」主题切换**：
  - 设置界面头部右侧新增 **自动 / 浅色 / 深色** 三段式主题切换器，切换后即时生效并保存至 `config.toml` 的 `theme_mode` 字段（默认 `system` 跟随 Windows 系统主题）。
  - 在「自动」模式下支持实时监听系统深浅色切换事件，切换主题后主动同步窗口配色与全窗口重绘。
- **深浅色层级优化与实时未保存状态提示**：
  - 引入统一的 `ThemeTokens` 配色体系，改善浅色模式下默认边框过深及卡片对比度问题，同时收紧显示器映射卡片间距与窗口尺寸并在标题旁展示当前版本号徽章（`v0.3.0`）。
  - 底部状态栏接入实时的已保存基线比对逻辑：改动任意未保存配置时高亮提示点击「保存并应用」生效；若手动还原至原配置或保存成功后，提示自动清除并恢复就绪状态。

### 文档更新
- 同步完善 `README.md` 中的多显示器固定音量、活跃音频过滤、实时切换日志、主题切换与配置文件/日志说明。

### 下载说明
- **`SoundCast_v0.3.0.msi`**（推荐）：Windows 安装包（`perMachine` 模式），支持覆盖升级 `v0.1.0` / `v0.2.0` 并自动保留原有安装路径与用户配置。
- **`SoundCast_v0.3.0.zip`**：绿色便携压缩包，解压后即可运行。
