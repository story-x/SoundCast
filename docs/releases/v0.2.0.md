## SoundCast v0.2.0 功能更新发布

本次版本围绕 **多显示器独立音量管理**、**仅切换有音频输出的应用** 与 **可视化切换日志** 进行重点增强，提升多屏办公与影音娱乐时的可控性与可观测性。

### 新增与改进
- **按显示器可选固定设备音量**：
  - 在每个显示器映射卡片中新增“固定设备音量”复选框与 `0~100%` 滑块，勾选时自动读取该绑定播放设备当前的系统主音量，松开滑块可即时预览效果。
  - 仅在应用切换音频端点或窗口跨显示器移动时自动同步对应设备音量，在同屏内切换不同窗口不会反复覆盖手动微调的音量。
  - 配置保存在 `config.toml` 的 `monitor_volume_map` 中，兼容旧版配置无缝升级。
- **默认仅切换正在输出音频的应用**：
  - 仅对当前存在活跃音频输出会话（`AudioSessionStateActive`）的进程及其同路径音频子进程执行切换。
  - 普通无声音窗口（如资源管理器、记事本、代码编辑器等）切换与移动时不再触发设备切换、音量调整或日志记录。
- **实时音频切换日志与托盘快捷入口**：
  - 设置界面顶部新增 **「规则与设备配置」 / 「切换日志」** 标签页切换，并在切换日志中实时展示最新切换记录（默认最多滚动保留 500 条于 `switch.log`）。
  - 每条日志包含切换时间、应用图标与友好名称、进程名、**原播放设备 -> 目标播放设备**、目标显示器及音量调整结果，并支持一键刷新、用编辑器打开日志文件与清空日志。
  - 系统托盘右键菜单新增 **「查看切换日志...」** 快捷入口，可直达日志标签页。

### 下载说明
- **`SoundCast_v0.2.0.msi`**（推荐）：Windows 安装包（`perMachine` 模式），支持覆盖升级 `v0.1.0` 并自动保留原有安装路径与用户配置。
- **`SoundCast_v0.2.0.zip`**：绿色便携压缩包，解压后即可运行。
